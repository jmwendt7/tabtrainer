Send tabs to Tab Trainer

iPhone (Safari)

  1. Tap Copy above.
  2. Tap Share → Add Bookmark, save it as "Send to Tab Trainer".
  3. Open Bookmarks, long-press it → Edit, replace the address with the copied text, Done.
  4. On a GuitareTAB tab page, optionally select the tab text, then tap Bookmarks → Send to Tab Trainer.

Android (Chrome)

  1. Tap Copy above.
  2. Bookmark any page (⋮ → ☆), then edit the bookmark: name "Send to Tab Trainer", paste the copied text as the URL.
  3. On a GuitareTAB tab page, type "Send" in the address bar and tap the bookmark suggestion (opening from the Bookmarks list won't run it).
